# Distribution Guide

Everything in this repository is released under the root
[LICENSE](/Users/bassamfaraj/PhoneixHovaN-1/LICENSE) (MIT). MIT is
permissive by design: you can copy, modify, perform, publish, sublicense,
and sell copies, as long as the original copyright and license notice is
included with any substantial portion you redistribute.

Below are domain-specific notes for how that typically plays out in
practice.

## Music — [Neon Echo](/Users/bassamfaraj/PhoneixHovaN-1/music/neon-echo)
- Free to record, perform live, release on streaming platforms, or sample.
- If releasing commercially, keep a copy of the LICENSE file alongside the
  release metadata (liner notes, description, or repo link) as attribution.

## Film — [Copper Comet](/Users/bassamfaraj/PhoneixHovaN-1/film/copper-comet)
- Free to produce, adapt into a longer feature, or submit to festivals.
- Credit the script as "based on an original screenplay, MIT licensed" in
  the production's credits or press materials.

## Art — [Glass Horizon](/Users/bassamfaraj/PhoneixHovaN-1/art/glass-horizon)
- The `generate_art.py` script and its rendered `.svg` outputs are both
  covered by the license — regenerate new variations with any `--seed`.
- Prints, NFTs, merch, or gallery use are all permitted; keep attribution
  in exhibition notes or product descriptions.

## Tech — [Silent Static](/Users/bassamfaraj/PhoneixHovaN-1/tech/silent-static)
- Standard MIT open-source distribution: publish to PyPI, vendor it into
  another project, or fork it freely. Keep the `LICENSE` reference in the
  package metadata (already set in `pyproject.toml`).

## Sports — [Wild Marathon](/Users/bassamfaraj/PhoneixHovaN-1/sports/wild-marathon)
- Free to run leagues, tournaments, school PE units, or app-based scoring
  tools around these rules. Credit the rulebook source if publishing an
  official/branded ruleset derived from it.

## General notes
- All codenames (Neon Echo, Copper Comet, Glass Horizon, Silent Static,
  Wild Marathon) are working titles — rename freely for your own release;
  renaming does not affect the license terms.
- No trademark rights are claimed over any codename; treat them as
  placeholders to replace with your own branding if you take a project to
  market.
