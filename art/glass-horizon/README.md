# Glass Horizon (Art)

An original generative art piece: a city skyline glowing under a sunburst of
translucent glass shards. Deterministic and reproducible via a seed.

## Regenerate
```bash
python3 generate_art.py --seed 42 --out artwork_001.svg
```

Included renders:
- [artwork_001.svg](./artwork_001.svg) (seed 42)
- [artwork_002.svg](./artwork_002.svg) (seed 7)

Change `--seed` for infinite variations of the same concept.
